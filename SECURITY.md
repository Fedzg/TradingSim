# Security / Sicurezza

[English](#english) · [Italiano](#italiano)

## English

Keep Alpaca Paper keys, the Telegram bot token, and the Codex login in their
private files or volume. Do not attach account dumps or worker logs to public
issues. Report security problems privately to the repository owner. Include
the affected version and steps using simulated data. If a credential is
exposed, revoke it at its provider and replace it in the worker configuration.

## Italiano

Conserva le chiavi Alpaca Paper, il token del bot Telegram e il login di Codex
nei rispettivi file o volumi privati. Evita di allegare dati del conto o log del
worker a segnalazioni pubbliche. Segnala i problemi di sicurezza in privato al
proprietario del repository, indicando la versione e i passaggi con dati
simulati. Se una credenziale viene esposta, revocala presso il provider e
sostituiscila nella configurazione del worker.
