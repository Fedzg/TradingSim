# Contributing / Contribuire

[English](#english) · [Italiano](#italiano)

## English

Make focused changes on a separate branch. Run `bun test` with Bun 1.3.14
on Linux, WSL 2, or the Docker worker image. Use simulated services for
failure tests and keep operational containers and volumes separate.
Describe what changed and what you verified in the pull request.
Never include credentials, Paper account data, or runtime state.

## Italiano

Lavora su un branch separato e mantieni la modifica circoscritta. Esegui
`bun test` con Bun 1.3.14 su Linux, WSL 2 oppure nell’immagine del worker.
Usa servizi simulati per le prove di guasto e separa container e volumi
operativi da quelli di prova. Nella pull request descrivi la modifica e le
verifiche. Tieni fuori credenziali, dati del conto Paper e stato operativo.
